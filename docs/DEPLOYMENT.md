# Deployment

Same hosting pattern as the Video_Game_Stats_Tracker template.

## 1. Database — Supabase

1. Create a project (choose a US region, e.g. `us-east-1`).
2. SQL Editor → run `db/schema.sql`.
3. Copy the **Transaction pooler** connection string (port 6543).

## 2. API — Render

1. Render → **New → Blueprint** → select this repo (uses `render.yaml`).
2. Set the secret environment variables in the dashboard:

| Variable | Value |
|---|---|
| `DATABASE_URL` | Supabase pooler connection string |
| `JWT_SECRET_KEY` | auto-generated by the blueprint (or your own long random string) |
| `ALLOWED_ORIGINS` | your Vercel URL, e.g. `https://your-site.vercel.app` (comma-separate several) |
| `BOOKING_URL` | your Calendly / Cal.com link |
| `PRICE_PER_RUNTIME_MINUTE_USD` | your rate |

3. Deploy, then open `https://<your-api>.onrender.com/health` →
   `{"status":"ok","database":"connected"}`.

## 3. Website — Vercel

1. Vercel → **Add New → Project** → import this repo.
2. **Root Directory:** `web`.
3. Environment variables:

| Variable | Value |
|---|---|
| `NEXT_PUBLIC_API_URL` | `https://<your-api>.onrender.com` |
| `NEXT_PUBLIC_BOOKING_URL` | your booking link (fallback) |
| `NEXT_PUBLIC_SITE_NAME` | your brand name |

4. Deploy. Add the resulting URL to `ALLOWED_ORIGINS` on Render.
